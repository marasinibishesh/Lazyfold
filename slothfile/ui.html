History

Every run is recorded in a journal. Undo puts files back where they were and never overwrites anything.

Storage cleanup

Finds temporary files and caches in your user folders (the safe version of Windows+R → %temp%). Only files older than a day, of known temporary types, in known cache folders are offered. Personal-looking and unknown files are always kept. Nothing is removed until you choose and confirm.

Recycle Bin

Scan to see how much the Recycle Bin holds.

Emptying is permanent. SlothFile asks separately and never does it as part of another action.

What SlothFile deliberately doesn't touch

C:\Windows\Temp and Windows Update files need administrator rights. Use Windows' own Settings → System → Storage → Temporary files for those. Prefetch is not clutter: clearing it makes apps start slower. SlothFile never asks for administrator rights.

Do it for me

The automatic run moves only the kinds of file you trust below, and only when the rules are very sure. Documents and anything the AI influenced always wait for your review. Every automatic run can be undone from History.
